# Quickread Chrome extension

Speed read the current page or a text selection in Quickread.

## Install (dev)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this `extension/` folder

## Use

- Click the Quickread toolbar icon to speed read the current page
- Right-click selected text → **Speed read selection in Quickread**
- Right-click the page → **Speed read this page in Quickread**
- Shortcut: **Alt+Q** (Mac and Windows)

## Settings

Right-click the extension icon → **Options** to change the Quickread app URL (defaults to the Render deployment).
